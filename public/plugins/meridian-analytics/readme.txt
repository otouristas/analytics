== Description ==

Meridian Analytics is a modern analytics platform engineered for fast, clean, cookieless telemetry.

Features:
* Zero cookie requirement — no consent popups needed
* Real-time Great-Circle 3D globe and flat map visualizations
* Automatic WooCommerce order synchronization with server-trusted webhook reconciliation
* Low script overhead (<2.4 KB minified)
* Native exclusion rules for admin and staging routes

== Installation ==

1. Upload the `meridian-analytics` directory to `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to Settings -> Meridian Analytics and enter your Property Write Key
